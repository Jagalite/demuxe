# Native A/V plus mpv subtitles: stamped-runtime comparison

[Raw trials, one-second process samples and fixture hashes](result.json) · [reproduction script](../../../tests/mpv-subtitle-tier-benchmark.mjs)

Chrome 153.0.8010.53 on macOS, three alternating pairs per fixture, one fresh
browser per trial. The campaign served a frozen local `web/` runtime snapshot after the
generated-file SPDX stamp; its file hashes and the fixture hashes matched at the beginning and
end, and Git HEAD stayed unchanged. Forced Hybrid is the previous subtitle
route; the automatic
candidate selected `native-direct-mpv`. The browser owned A/V in the candidate,
and the mpv subtitle service reported zero audio/video decode chains. All 12
trials passed startup, eight seconds of steady playback, forward/backward
seeks, EOF and worker teardown. The local H.264/AAC fixtures and runtime files
are identified by SHA-256 in `result.json`.
The candidate reported a 64 MiB subtitle Wasm heap and six worker URLs per
trial; forced Hybrid reported eleven worker URLs.

| Fixture | Route | Chrome CPU, % of one core (three trials; median) | Startup median | Seek to 10 s / 1 s, median | Peak **sampled** summed Chrome RSS, median | Renderer task time over steady window, median |
| --- | --- | --- | ---: | --- | ---: | ---: |
| H.264 + AAC + embedded SRT / MKV | forced Hybrid | 43.6 (43.6, 43.0, 62.2) | 1,187 ms | 441 / 443 ms | 1,105,280 KiB | 0.08 s |
| same fixture | automatic Native Direct + mpv subtitles | 40.2 (40.2, 38.4, 54.0) | 1,323 ms | 39 / 38 ms | 1,046,448 KiB | 0.08 s |
| H.264 + AAC + styled ASS / MKV | forced Hybrid | 61.1 (62.9, 61.1, 60.8) | 1,130 ms | 261 / 440 ms | 1,060,224 KiB | 0.18 s |
| same fixture | automatic Native Direct + mpv subtitles | 51.6 (51.7, 51.6, 51.6) | 1,294 ms | 41 / 39 ms | 1,030,880 KiB | 0.27 s |

CPU is the delta of CDP CPU time for the complete Chrome process set divided
by elapsed steady time. Every trial recorded nine samples at roughly one-second
intervals and asserted that the CDP and `ps` process sets stayed identical.
The raw result retains each process ID, type, CPU time and RSS at each sample.
The RSS number is the maximum **sampled** sum, not a continuous peak; shared
pages can be counted more than once. CPU excludes OS media services. The host
was shared, so these are workload-specific comparisons rather than an isolated
machine ranking. The startup check includes player open, play and progression
past 0.5 seconds. The candidate had slower median startup in both cases. Its SRT trial CPU
varied from 38.4% to 54.0%; Hybrid varied from 43.0% to 62.2%. The SRT CPU
difference is small relative to this spread and does not support a broad
performance ranking. The ASS median was 51.6% versus 61.1% for Hybrid in
this matched campaign. No competitor was rerun in this campaign.

The [adverse-condition run](adverse.log) added default-second SubRip,
absent or unresponsive optional service assets and blank startup output
regressions to [`tests/mpv-subtitle-adverse.mjs`](../../../tests/mpv-subtitle-adverse.mjs).
Native admission checks the optional module and Wasm files before selecting
the route. The selected track must produce an overlay at the current time or
at one of 0, 1, 2, 5, 10, 20 or 30 seconds; otherwise automatic selection
retains Hybrid/Software. This conservative test can reject a valid file whose
cue timing misses every sample. The [Direct and Remux correctness rerun](correctness.log)
covers SRT, mov_text, ASS, PGS and VobSub. Original qualification is recorded
in the [prior report](../mpv-subtitle-tier-20260922-01/REPORT.md).
Bitmap/ASS fidelity remains limited to the authored fixtures in that report.

Reproduce after building the local service and fixtures:

```sh
python3 tests/mpv-subtitle-fixtures.py
npm run build
python3 scripts/check-licenses.py --stamp-generated
mkdir -p build/mpv-subtitle-service/benchmark-stamped-snapshot
rsync -a web fixtures build/mpv-subtitle-service/benchmark-stamped-snapshot/
DEMUXE_TEST_ASSET_ROOT=build/mpv-subtitle-service/benchmark-stamped-snapshot node tests/mpv-subtitle-adverse.mjs
DEMUXE_TEST_ASSET_ROOT=build/mpv-subtitle-service/benchmark-stamped-snapshot node tests/mpv-subtitle-generalization.mjs
DEMUXE_TEST_ASSET_ROOT=build/mpv-subtitle-service/benchmark-stamped-snapshot node tests/mpv-subtitle-tier-benchmark.mjs
```
