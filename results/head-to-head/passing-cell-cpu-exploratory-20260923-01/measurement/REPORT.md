# Exploratory passing-cell CPU campaign

Targeted 111 previously blank green pass cells across five lanes. Added README readings to 100 cells: 93 have at least one steady accepted window, 7 have only stalled full CPU windows, and 11 could not reach a CPU window because the source fixture was unavailable. 273 of 333 rounds were accepted; 26 additional full windows stalled. No fidelity checks were run and historic pass labels were preserved.

See [CPU-REPORT.md](CPU-REPORT.md) for medians, ranges, per-round records and exclusions. `†` marks a steady-window median; `‡` marks a stalled-window median that is not a steady-playback cost.
