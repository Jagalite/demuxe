# Subtitle-only mpv external clock audit

**Recommendation: KEEP CLOCK DESIGN, USE CHEAPER NON-RENDER UPDATE.** The current route was correct for the tested SRT and ASS cues. `update_subtitles(m, pts)` is already the non-render mpv call that advances demux and decoder state. It can be used separately when no new pixels are needed; the OSD render is still required on cue changes, resize, and animated ASS frames.

Browser `video.currentTime` (minus remux timeline bias) feeds the `NativeMpvSubtitles` animation-frame RPC. The worker detects time jumps and seeks, unblocks demux reads, then `subtitle_service_render` writes `m->playback_pts`, calls `update_subtitles(m, pts)`, and calls `web_subtitle_render`. In mpv, `update_subtitles` calls `sub_read_packets`; that polls `demux_read_packet_async_until`, calls the decoder's `decode`, and updates cached/visible subtitle state. The SRT path converts text to libass events; native ASS events are added to its libass track. `osd_render` calls `sub_get_bitmaps`, which reaches `ass_render_frame`; the bitmap bridge composites and copies changed pixels. Supplying PTS alone does not run the demux/decode update.

Headless Chrome, `native-direct-mpv`, zero mpv A/V chains; fixtures: `build/head-to-head/assets-component-isolation-01/fixtures/h264-srt/index.mkv` and `h264-ass/index.mkv` (single cue 0.5–35.8 s). Both showed visible pixels during play, pause, resume, 1.75× playback, and paused seek to 3 s. Paused video time stayed fixed; subtitle worker position followed browser video time within 0.04 s at sampled points. The ASS fixture is a drawn shape, so its `sub-text` is blank by design.

The isolated test-only bridge used the committed `native/subtitles/service.c` and added `subtitle_probe_update`, which calls only `update_subtitles` under the core lock. After a seek outside the cue (35.9 s), a seek to 1 s plus this update returned ready and restored the 0.5–35.8 s active cue for both fixtures; SRT text returned too. The native render counter did not increment (SRT 181→181, ASS 132→132). This proves non-render clock/state progress for these text formats, not a general performance win or a safe render-suppression policy for all subtitle codecs.

Probe: run `python3 experiments/subtitle-external-clock-audit/build.py`, then `node experiments/subtitle-external-clock-audit/probe.mjs`; machine output: `probe.json`. Concurrent uncommitted subtitle changes were present; the isolated bridge pinned committed service source at `07844047` to avoid mixing those changes with the built mpv library. Generated Wasm/cache files were removed after the run. No production files were edited by this audit.
