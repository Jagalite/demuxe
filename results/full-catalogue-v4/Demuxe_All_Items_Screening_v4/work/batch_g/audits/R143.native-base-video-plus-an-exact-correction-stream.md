## Bounded decision

Hypothesis: The mechanism 'Native base video plus an exact correction stream' may reduce work or add capability only while preserving its explicitly scoped output contract.

Contract: Exact declared source samples require identical base reconstruction, specified upsampling and signed correction semantics with full timing alignment.

Current opportunity/gap: Current browser-decoded frame path has no signed correction stream or base-reconstruction identity contract. Platform-varying base/color conversion can invalidate supposedly exact residuals.

Cheapest correct baseline: Direct exact software decode of original source under the same sample/color contract.

Primary outcome: Decision power, reproducibility or diagnostic cost without changing the measured player outcome.. No current metric was measured.

Bounded next test and falsifier: Define one prepared base/correction oracle tied to exact decoder reconstruction; deliberately different base reconstruction must reject rather than display approximate corrected output; count correction bytes/production.

Reopen when that named missing representation/owner/contract is provided or a changed workload exposes this exact opportunity. This is not a family-wide codec failure.
