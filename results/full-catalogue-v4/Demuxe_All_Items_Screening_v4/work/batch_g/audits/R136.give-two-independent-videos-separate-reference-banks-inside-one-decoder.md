## Bounded decision

Hypothesis: The mechanism 'Give two independent videos separate reference banks inside one decoder' may reduce work or add capability only while preserving its explicitly scoped output contract.

Contract: Prepared compatible streams use distinct valid reference banks and produce both exact independently decoded outputs with original source mapping.

Current opportunity/gap: WebCodecs accepts conventional full AV1 chunks and owns references opaquely; no prepared alternating-stream encoder/reference-slot contract exists. Two unrelated videos cannot be interleaved safely by changing timestamps.

Cheapest correct baseline: Two independent decoder sessions with matched bounded concurrency.

Primary outcome: User-visible operation latency, duplicated work or peak/steady live resource ownership; not object counts alone.. No current metric was measured.

Bounded next test and falsifier: Provide a tiny authored AV1 reserved-slot pair and bitstream reference-state oracle before using one decoder; cross-bank reference or changed shared sequence state must fail.

Reopen when that named missing representation/owner/contract is provided or a changed workload exposes this exact opportunity. This is not a family-wide codec failure.
