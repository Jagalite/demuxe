## R212 — Vectorize across independent streams rather than time

A native AVX2 benchmark decoded eight independent IMA-ADPCM state machines in SIMD lanes. All 12,000,000 output samples matched the scalar implementation exactly. Best measured time was 21.76 ms scalar versus 10.49 ms AVX2, a **2.07×** speedup.

This is strong evidence for cross-stream SIMD on this recurrence, not a claim about a complete browser/FFmpeg audio pipeline.

## Bounded decision

Hypothesis: The mechanism 'Vectorize across independent streams rather than time' may reduce work or add capability only while preserving its explicitly scoped output contract.

Contract: Only genuinely concurrent independent streams may occupy SIMD lanes; preserve each exact state/sample sequence and latency.

Current opportunity/gap: Current player produces one selected audio stream, not eight independent IMA state machines. Cross-stream SIMD requires simultaneous independent demand absent from this playback profile; adding dummy streams would create an artificial gain.

Cheapest correct baseline: Existing one-stream IMA decoder for ordinary single-player audio.

Primary outcome: User-visible operation latency, duplicated work or peak/steady live resource ownership; not object counts alone.. No current metric was measured.

Bounded next test and falsifier: Reopen when actual multi-stream workload exists; compare bounded lane batching to optimized scalar streams and reject latency added solely to fill lanes. AVX2 host speed is not Wasm128 speed.

Reopen when that named missing representation/owner/contract is provided or a changed workload exposes this exact opportunity. This is not a family-wide codec failure.
