## R173 — preserve FLIC indices plus palette

The controlled 16×8 FLC has four meaningful state transitions: initial palette+indices, palette-only, index-only, then another combined update. A small state machine preserves the 128-byte index plane and 768-byte palette separately. Expanding that state to RGB matches FFmpeg exactly for all frames, including the palette-only update. Replaying state from the beginning to the seek target reproduces the same RGB hash.

This validates palette/index retention and the seek-state requirement. Browser shader lookup remains untested because the environment exposes no WebGL/WebGPU context.

**Integration implication:** this is a legitimate indexed-image route only if palette state is part of the seek dependency graph. Palette-only packets are presentation-significant even when index bytes do not change.

## Opportunity and first-pass conclusion

Current software presenter accepts 420 planes or RGB fallback, not indices/palette updates. Retaining FLIC palettes needs a stateful representation and seek reconstruction, rather than changing a texture format alone.

Contract: Each palette-only/index-only transition and seek reconstructs exact RGB; palette state is a decode dependency.

Cheapest correct baseline: FFmpeg RGB expansion of the same FLC sequence, including palette-only transition and replay-to-seek.

Primary outcome: a faithful additional capability or removable current work; no local performance measurement was made.

Bounded next test: Expose one bounded index+palette frame state adapter and compare four controlled transitions to FFmpeg before shader integration.

Falsifier/adverse control: Palette-only packet with unchanged indices must visibly change colors and survive a seek replay.

Reopen: the specifically missing adapter, representation or observed capability in the next test becomes available; a report from a different environment alone does not satisfy this gate.

Limits: source report observations are historical assertions only; raw historical runs were not imported or rerun. This verdict is per mechanism identity, not a family-wide failure.

Explicit hypothesis: Test whether preserve FLIC indices plus palette provides the declared output through less work or a faithful additional route.
