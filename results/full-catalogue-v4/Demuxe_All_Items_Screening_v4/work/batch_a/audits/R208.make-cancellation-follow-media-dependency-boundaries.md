## R208 — Make cancellation follow media dependency boundaries

Exact WebTransport testing is **BLOCKED** because `WebTransport` is undefined in the permitted opaque/non-secure browser context. A bounded independent-GOP scheduler model nevertheless validates the critical state rule: after a seek increments the presentation epoch, a deliberately uncancelled old GOP may complete but cannot publish.

The model is not transport performance evidence. Its byte accounting also shows independent speculative streams are not automatically better than a clean HTTP-range abort; scheduling policy matters.

## Opportunity and first-pass conclusion

Current seek increments generation and terminates source/remux workers, with decoder stale-frame closure. That supports cancellation safety but is not independent-GOP transport scheduling. No WebTransport dependency-stream owner is present.

Contract: Obsolete dependencies may finish only without publishing stale frames; retain needed dependencies and source authorization.

Cheapest correct baseline: Current bounded HTTP-range abort and generation-rejecting remux restart on identical source dependencies.

Primary outcome: a faithful additional capability or removable current work; no local performance measurement was made.

Bounded next test: Define one two-GOP delivery adapter and compare retained required GOP versus canceled speculative GOP using the current generation publication boundary.

Falsifier/adverse control: Deliberately let obsolete GOP complete after seek and verify zero publication in the new epoch.

Reopen: the specifically missing adapter, representation or observed capability in the next test becomes available; a report from a different environment alone does not satisfy this gate.

Limits: source report observations are historical assertions only; raw historical runs were not imported or rerun. This verdict is per mechanism identity, not a family-wide failure.

Explicit hypothesis: Test whether make cancellation follow media dependency boundaries provides the declared output through less work or a faithful additional route.
