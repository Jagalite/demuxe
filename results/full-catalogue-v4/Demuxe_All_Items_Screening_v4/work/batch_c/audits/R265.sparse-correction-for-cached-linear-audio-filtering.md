57: ## R265 — sparse correction for cached linear audio filtering
58: 
59: A 1,200,000-sample integer signal was filtered with a 129-tap FIR. A 6,000-sample edit produced `Δx`; only `h*Δx` was recomputed and added to the cached output.
60: 
61: **Result.** The patched output is exactly equal to a full recomputation. The correction support is 6,128 samples, including the FIR tail; omitting that tail fails the oracle. Median patch time was 1.061 ms versus 90.474 ms full, or 85.3× in this sparse-edit corpus.
62: 
63: **Boundary.** This identity is for linear time-invariant filtering. Nonlinear/stateful effects, adaptive filters, compressors, limiters, reverbs with external state, format changes, and resampling need separate dependency/state analysis.
