66: 
67: The 2-second 7.1 FLAC contains 84 frames and eight independent fixed-predictor subframes. The candidate entropy-parses every subframe to remain synchronized but runs predictor reconstruction only for channels 0–3 (L/R/C/LFE), skipping reconstruction for channels 4–7. The four selected 96,000-sample channels match FFmpeg's full eight-channel decode exactly, and an integer stereo matrix derived from them is byte-exact to the same matrix computed from full PCM.

## Hypothesis and contract

For explicitly ignored independently coded subframes, avoid reconstruction not contributing to the requested matrix while still parsing necessary boundaries. Require exact requested output and handle decorrelation profiles separately.

Only channels proven unused by an explicitly requested matrix may skip reconstruction; entropy boundaries still parse and coupled assignments reject.
