81: ## R107 — separate AV1 base reconstruction from film-grain synthesis
82: 
83: The 6-second AV1 fixture carries film-grain syntax and applies grain on all **180 frames**. Decoding the **same encoded bytes** with libdav1d grain disabled changes the reconstructed output hash but reduces median host decoder CPU from **266.5 ms to 237.8 ms (10.8%)** and wall time by 7.9%.
84: 
85: This establishes the component boundary and cost in this decoder/fixture. It does **not** yet prove a faster fidelity-preserving pipeline: separately reproducing AV1 grain outside the decoder was not implemented, and grain-disabled output is intentionally different.
