## Source excerpt / declared hypothesis

Type: Prepared-media construction; high-risk follow-on to R135 and R142. Preserve a source picture as a non-displayed reference-building picture, and insert an independently coded edited picture that is displayed but does not refresh the reference slots. Later source pictures could then continue using their original references rather than requiring re-encoding solely because of the visual edit. AV1 distinguishes display decisions from reference refresh decisions. Its syntax includes show_frame, INTRA_ONLY_FRAME, and refresh_frame_flags; the reference-update process stores picture and auxiliary state in the selected slots. These primitives do not establish the complete proposed edit operation. [A1–A3]
