# MediaBunny adapter release review inventory

This is a review aid for the isolated `feature/mediabunny-provider-adapters` worktree at HEAD `9702315e7aac272c718cd14ae190b8b37b7a3140`. It is not a review approval or a release qualification. The original checkout is separate. The [machine-readable inventory](../packages/provider-mediabunny/qualification/core-review-inventory.json) binds all current core inputs, the HEAD blobs, the existing qualification record and the inventory script by SHA-256.

The current core manifest lists 236 inputs. Seventeen differ from or are absent at this worktree's HEAD: 14 modified files and three new files. The other 219 are unchanged from HEAD, but only 26 of those match the existing qualification record; 43 differ and 150 are unrecorded. Across all 236 current inputs, the existing record contains 79 paths: 26 current hashes match, 53 differ and 157 are unrecorded. HEAD itself is not a qualification. The current local core candidate's input inventory agrees with these 236 current hashes.

The [failure output](../packages/provider-mediabunny/qualification/core-review-release-gate-failed.txt) is retained. That first failure is not the entire drift; updating one hash would not review the other inputs. The qualification record was not changed. The optional package remains private and its `prepack` guard rejects release packaging.
