## Changes

- Retain player source-control, autoplay, preview-label and timeline-targeting updates from fbd15d49.
- Preserve keyboard focus on timeline or volume when asynchronous autoplay completes.
- Retain the native event-wait timeout cleanup already included in qualification commit 68bbb450.

- Advance player/core metadata to beta.6 and derive default test archive names from package version.

## Reduced release gate

The user authorized skipping unrelated requalification but explicitly requires resolution of the observed Chrome worker-cleanup and Firefox PCM-startup failures before release.

Required: build/types and API contracts; focused actual controller/worklet regressions; three-browser player controls and loaded-video sequences; exact archive source/license/integrity checks; offline installation, imports and asset copying; focused Firefox PCM and Chrome cleanup checks.

Deferred: complete codec catalogue reruns, engine rebuilds when all recorded native inputs and binary hashes remain unchanged, CPU/frame-rate comparisons and long endurance. No new performance or format-support claim follows from this reduced gate. The standard full release verifier is not weakened or represented as passed.

## Outstanding evidence

Chrome's original worker-cleanup deadline failure remains unexplained. Controlled diagnostics pass, but those passes do not establish its cause or constitute a fix. Intermittent WebKit activation timeouts also remain recorded; an instrumented component run passes, with no evidence yet supporting a runtime or deadline change. These observations must be adjudicated before claiming release readiness.

The candidate is not authorized for npm publication or a public release tag merely by completing this preparation.
