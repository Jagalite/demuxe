# Demuxe focused research batch 8

Start with [REPORT.md](REPORT.md) and [LOCAL_AGENT_HANDOFF.md](LOCAL_AGENT_HANDOFF.md).

The package contains executed standalone prototypes and recorded observations for D40–D43. It does not contain a patch to Demuxe. Tests use authored audio only; there are no third-party media assets or font files.

## Dependencies

Python 3.10+ with `numpy` and `playwright`; a Chromium executable; FFmpeg/ffprobe built with libopus; shared `libopus` discoverable by the OS. The delivered runtime versions are in `evidence/environment.json`. The default browser executable is `/usr/bin/chromium`; override it with the `CHROMIUM` environment variable.

Run from this directory:

```sh
python scripts/run_all.py
# Or recheck delivered evidence without running media again:
python scripts/verify.py
```

The browser executes a standalone page with bytes supplied by the local Python harness, not a live website or the maintained Demuxe player. Decoder outputs are never played aloud: capture nodes emit silence. Tests do not require a network media source.

95 consistency checks passed on the delivered evidence. Some checks require an incorrect route to fail; inspect scientific_outcomes in the JSON rather than counting all tests as candidate passes. No measured CPU/energy or production speed claim is included.

`SHA256SUMS.json` covers package contents except itself. Encoder/container metadata can differ across new runs; compare outputs within the new run before comparing hashes to archived inputs.

Scripts are provided under MIT; reports under CC BY 4.0, following the research package convention. `sha256.js` is reused from the prior delivered Batch 7 utility. No Demuxe source code is bundled. External implementations are dependencies, not relicensed by this package. Synthetic fixtures are generated by the scripts and may be reused for testing.
