## Reproduce in a separate copy

Dependencies: Python 3.13, NumPy, Pillow, Playwright, system Chromium, FFmpeg/FFprobe with libx264/libopus and the native Opus decoder. The original environment is recorded in `evidence/environment.json`. Default Chromium path is `/usr/bin/chromium`. All fixtures are synthetic; no repository checkout, remote media or network server is required by these experiments.

A rerun overwrites output/evidence paths, so use a copy to preserve archived observations. Host-side FFmpeg is used for fixture construction, packet-copy remuxes and output oracles. The tests do not measure browser Wasm or the maintained Demuxe code.

```bash
python scripts/build.py
python scripts/crop_followup.py
python scripts/build_same.py
python scripts/opus_stream.py
for stage in first cropfollow epochs sameaspect boundary recovery clip opusstream monostream; do
    python scripts/run_browser.py "$stage"
done
python scripts/host_checks.py
python scripts/extra_audio_oracle.py
python scripts/verify.py
# Expected in the recorded environment: exit 1 for the retained default-decoder failure.
```

The archived `evidence/initial/` files document exploratory harness failures/corrections; they are not automatically regenerated by the final recipe. `host_checks.py` deliberately uses separate source-defined interval decodes after the failed changing-resolution single-PNG-encoder attempt. It does not claim uninterrupted host-output equality.

Code helpers are isolated, restricted research implementations, not security-hardened general parsers. Do not directly expose them to unbounded/untrusted input in production. Browser guard state in recovery.js is a simulation, not an implementation of maintained Demuxe ownership.
