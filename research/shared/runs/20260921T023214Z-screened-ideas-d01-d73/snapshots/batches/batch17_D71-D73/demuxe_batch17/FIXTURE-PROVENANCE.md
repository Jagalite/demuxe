# Fixture and implementation provenance

All imagery is generated by scripts/build.py as numerical RGB arrays with ordinal marker patches. FFmpeg encodes those original arrays with AVC/VP9. Derived fixtures modify framing, duration, order, or presentation metadata while retaining the traced compressed payloads. No commercial video or external image corpus was used. Source imagery is CC0; code is MIT; reports are CC-BY-4.0. Code helpers `common.py` and `sha256.js` derive from the prior user-provided Demuxe research batch 15 package, where they carried MIT SPDX headers. The other scripts were authored for this batch. No external engine implementation is redistributed.

Preparation includes whole input arrays, host decode oracles, full fixture materialization and browser instrumentation. These are experiments, not a production zero-copy implementation or a performance benchmark. Browser flags and installed versions are in evidence/environment.json.

Two combined tool invocations hit their wall-time limits during staged execution; records completed before the limit were retained and missing cases were subsequently completed. The candidate/output contracts were not relaxed to obtain passes. Adding frameWidth/frameHeight logging after the first reverse run did not change its output contract. A post-EOS duration setter attempt was invalid API use and is retained explicitly, not counted as a successful repair.
