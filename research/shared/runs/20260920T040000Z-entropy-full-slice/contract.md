# R120 / R134 qualification contract

Pinned source: https://github.com/OxideAV/oxideav-h264 at 552f9883f6dc5bbdf69441063e65e9cb27af614b (MIT). Independent oracle: installed host FFmpeg H.264 decoder. Original source media are generated testsrc2/smptebars patterns, never copied user media.

R120: translate actual 8-bit 4:2:0, progressive single-slice CABAC I/P H.264 to CAVLC. Supported macroblocks: intra4x4, intra16x16, PCM, P16x16/16x8/8x16 and P skip. Reject subpartitions, 8x8 transforms, FMO, constrained-intra and B slices. Preserve exact quantized coefficients, predicted motion differences, QP deltas and headers other than entropy mode and CABAC initialization bits. Translation must never invoke inverse transforms, motion compensation or pixel encoding. Compare every independently decoded YUV picture exactly. Change a residual coefficient as wrong-output control. Unsupported inputs must fail closed rather than copy an unsupported slice. This is a restricted profile, not generic AVC transcoding.

R134: persist an explicit full macroblock-boundary CABAC record with arithmetic cursor/range/offset, every context, macroblock position, prior QP/skip flags, full neighbor/motion/reference syntax grids and already parsed prefix syntax. Bind it to the exact RBSP and SPS/PPS/header. Restore in an entirely new process, do not parse prefix symbols, continue every remaining macroblock through slice termination, then write CAVLC and independently reconstruct every picture with host FFmpeg including I/P reference dependencies. Source reference frames are reconstructed by FFmpeg from the retained full translated sequence; no claim of suffix-only picture reconstruction or free DPB preparation. Charge retained prefix syntax and preparation. Omitted-neighbor control must change syntax/output or reject; changed source and corrupt record must reject. Fresh-process completion covers teardown and independence; interruption must leave only reusable finalized checkpoint files.

Correctness gates precede cost. Eight alternating whole-job measurements compare native FFmpeg decode/reencode lossless baseline versus entropy translation + independent decoding for R120 (baseline must prove exact same decoded pictures), and uninterrupted translation versus initial capture plus four independent restores for R134. Primary R120 cost is wall time of a complete one-use job; primary R134 cost is total wall time of five reconstructions including initial checkpoint creation and JSON serialization/retention. Require >=10% total-cost reduction to recommend a performance benefit; report cold process/setup and output-size tradeoffs separately. No production/browser hardware-playback or energy claim.
