# Full entropy translation and macroblock checkpoint qualification

Implemented a real CABAC→CAVLC quantized-syntax exporter/writer and a complete macroblock-boundary sidecar. Four progressive 8-bit 4:2:0 I/P profiles produce **78 exact independently decoded pictures**, **4,896 macroblocks**, and **117,746 nonzero coefficients**. Serialized syntax signatures also match before/after translation. No pixel reconstruction/requantization is called by the translator. Fresh-process restores skip the saved prefix entropy bins, continue all remaining macroblocks through slice termination, and reproduce the uninterrupted translated stream byte for byte. Half-slice restore was tested on all 78 pictures; boundary 1, 47 and 95 restores additionally cover 24 pictures each.

Changed coefficient produces independently different pictures. Omitting neighbor state rejects, corrupted checkpoint integrity rejects, wrong-source restore rejects, unsupported B input rejects without output. Interrupted capture after one finalized record leaves a valid atomic record and no output publication; subsequent capture/restore recovers exact output. V1 cursor-end guard failure and its correction are retained in the development notes and trace. A fresh pinned upstream clone, locked dependency build, and complete rerun passed.

**R120 pursue, restricted entropy-conversion profile.** Final rebuilt eight alternating complete-job pairs cost median **0.824175×** exact-picture lossless decode/reencode-to-CAVLC baseline including independent output decoding, process creation and output I/O (range 0.792708–0.846725; bootstrap percentile interval 0.811073–0.832158). CAVLC candidate 70,639 bytes vs pixel-reencode 153,570 bytes on the cost fixture; original CABAC is 63,404 bytes. The candidate preserves original quantized syntax; the pixel baseline only preserves decoded pictures. Earlier complete-job variants had median 0.813548 and 0.822545, all retained. No claim against passthrough, no Baseline-only decoder compatibility or browser playback tier claim.

**R134 stop current full-slice JSON checkpoint profile.** Five complete reconstruction jobs include initial capture/generation plus four fresh-process restores, prefix/source retention, serialization and every independent decode. Final median **1.477290×** uninterrupted translation/reconstruction (range 1.074346–1.958123; bootstrap interval 1.328484–1.498990), failing the predeclared <=0.9 threshold. Earlier variants cost 1.416732 and 1.463666. Midpoint records for the 24-picture cost stream total **5,548,281 bytes**, versus 63,404 source bytes. This is a measured full-grammar/complete-picture-workflow negative, not the earlier residual-only component cost. It does not skip prefix pixel reconstruction or supply a standalone DPB capsule; those costs remain charged.

Cold clean checkout was 0.96 s and locked build 23.03 s, reported separately from prebuilt per-job runtime. Native fixtures are deliberately restricted; broader content, browser loading/hardware/physical energy and production integration remain outside these research conclusions.
