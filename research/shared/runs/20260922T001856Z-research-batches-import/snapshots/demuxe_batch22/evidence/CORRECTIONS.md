# Retained corrections and limitations

1. Initial all-field FFprobe equality was false for the interleaved first AAC packet: FFprobe reports its duration as 1024 ticks, while it omits that field for the original and explicit grouped layouts. The actual tfhd/trun duration is unchanged. Checks now separate payload/PTS/DTS/size identity, raw table identity, and the reporting discrepancy. Initial build logs remain.
2. A verifier diagnostic initially expected this discrepancy in both grouped and interleaved layouts. It was corrected to match the inspected evidence. `verification_initial_diagnostic_check.json` is retained. No decoded-output threshold was relaxed.
3. Initial rawvideo oracle invocation allowed FFmpeg's frame-rate synchronization to duplicate a leading picture. The final oracle explicitly uses `-fps_mode passthrough`, producing exactly 75 source pictures. The original build log remains; both candidate and reference used the same corrected policy.
4. `browser_ledger_v0.py` is the actual first ledger, with coverage-based stale-content and cross-mutation pending-join failures. `browser_ledger.py` adds invalidation/order checks; its outcomes are separate, and the v0 failure remains reproduced.
5. The first ledger invocation reached the tool execution limit before the final generation case. That case was then executed and the complete matrix was run again in a clean directory. No unexecuted scenario is counted as passed.
6. ScriptProcessor live capture plus concurrent Canvas reads does not provide deterministic, sample-exact audio recordings. Their offsets and output sequences vary. Captures are retained as signal/diagnostic witnesses only; complete audio identity comes from independent host and browser whole-file decode comparisons. No A/V skew, acoustic continuity or hardware inference is made.
7. Raw live/whole audio blobs were initially emitted under the generic `.rgba` suffix by the inherited raw-artifact helper. They were renamed `.f32` and the helper corrected; their byte content and hashes did not change.
8. Interactive container sessions were unavailable. All clean replay stages were executed directly and observed; no background-delivery claim is made.
