# Move part of a software video decoder onto the GPU

Full identity: `R081.definition-not-recovered`.

Current decision: **stop_current_profile** (actual_compressed_decode_route_with_independent_picture_oracle).

Strengthened beyond the prior 64x64 screen: actual 256x256 and 512x512 MPEG2 DC-I plus 32 chroma-aligned motion-only P pictures now parse from compressed bytes in both timed browser paths. All 33 independently FFmpeg-decoded pictures per size and all 88 timed outputs match exactly. Wrong DC/motion, restored source state, mismatched dimensions and closed owners are checked. Optimized CPU uses coalesced typed-array row copies, with reusable buffers in the persistent case. Cold median GPU/CPU ratios are 2.078947 and 1.887640; persistent warm medians 1.656250 and 1.818182, and setup+11jobs+teardown totals 1.704023 and 1.783516. Zero GPU-faster pairs in all four 11-pair sets. This is a measured scoped negative for actual software entropy plus GPU partial reconstruction, not a postdecode-copy substitution or universal GPU-decoder conclusion.

Next action: Stop the measured DC-only-I/integer-motion-P CPU-visible-output profile. Reopen for materially different faithful codec work, kernels or GPU-resident output contract that passes independent all-picture correctness and a matched end-to-end cost gate; do not extrapolate this result to arbitrary codecs or production routing.
