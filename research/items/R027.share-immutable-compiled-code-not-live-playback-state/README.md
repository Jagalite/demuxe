## Definition and contract

Proposed mechanism. Use single-flight loading of hash-identified Wasm modules and optional shader/font assets. Create fresh mutable instances for each source. Consider a small decode-only/prepare-only module split only when measured startup justifies its packaging complexity. Source basis. Official WebAssembly guidance discusses separating compilation from instantiation and worker reuse. Demuxe already has optional plan prerequisites; module availability should be explicit rather than an undocumented local-build dependency. [E2, D1]
